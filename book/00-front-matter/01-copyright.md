**A note on how this book was made**

An AI system drafted this book from the sources I gave it: five articles and papers, four web links and two files of notes. I set the question, chose what to keep, argued with the drafts and put my name on the result. The errors are mine.

The objection worth taking seriously is not that a machine wrote it. It is that nobody checked it. So the numbers are checked. Each comes from a named source, each one taken from a scanned page was compared with the page image, and Appendix A lists what was verified and what was not. I did not run Jev myself. No live call was made, and every measurement here belongs to whoever ran it.

Two more things you should know. Some chapters open with a composite scene, a pattern distilled into one moment. If an opening has no footnote, read it as a parable. And the ideas in the accountability chapter come from notes that describe risks a decision system could have. They allege nothing about any named provider, and neither does this book.
