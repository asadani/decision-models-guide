Required caption if an external image is eventually used:

> Figure N. [Plain-language description]. Image credit: [named rights holder]. Source: [linked original article, date]. Used under [verified license or permission]. [Describe any modifications].

Maintain an asset record with file path, original image URL, source article URL, rights holder, license/permission evidence, alt text, modifications and access date. Credit is mandatory when using an external image; it does not replace the permission check.
